# NixOSascii
NixOS .gif animation in Terminal/PowerShell


HOW TO INSTALL: 
1. Install Python (https://www.python.org/)
2. pip install pillow (https://pypi.org/project/pillow/)
3. git clone https://github.com/akx25/NixOSascii
