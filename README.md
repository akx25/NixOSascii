# NixOSascii
NixOS .gif animation in Terminal/PowerShell


HOW TO INSTALL: 

Copy & Paste this to Terminal/PowerShell

git clone https://github.com/akx25/NixOSascii.git
cd NixOSascii
pip install pillow
python NixOSascii.py
